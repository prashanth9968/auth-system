# 🔐 Authentication System (Spring Boot + JWT + OTP)

A secure authentication system built using **Java, Spring Boot, JWT, and OTP verification**, inspired by real-world authentication mechanisms.

---

## 🚀 Features

* User Registration & Login
* JWT Authentication
* Password Encryption (BCrypt)
* OTP Verification (Email-based)
* QR-based OTP concept (inspired UI)
* Secure REST APIs

---

## 🛠️ Tech Stack

* Java 17
* Spring Boot
* Spring Security
* JWT
* MySQL / PostgreSQL
* HTML, CSS, JavaScript

---

## 🧠 Architecture

Frontend → Spring Boot → Database → OTP Service

---

## 🔐 Security

* Encrypted passwords
* Token-based authentication
* Stateless sessions

---

## 📂 Modules

* Authentication Service
* OTP Verification Service
* User Management

---

## ▶️ Run Project

```bash
mvn spring-boot:run
```
